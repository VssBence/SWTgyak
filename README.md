💣 Egy Keep Talking and Nobody Explodes szerű, böngészőalapú kooperatív játék, amelyet egy egyetemi kurzus keretében fejlesztünk.

A játékról

Két játékos vesz részt: az egyik a képernyőn látja a "bombát" és annak moduljait (LED-ek, gombok, kijelzők), a másik pedig egy útmutatót olvas, amely leírja, hogyan kell azokat hatástalanítani. A két játékos csak kommunikáció útján tudja megoldani a feladatot.

Technológiák

Frontend: HTML, CSS, JavaScript
Backend: C# / ASP.NET Core (valós idejű kommunikáció)
